# Áudios da urna

O simulador usa a camada `enhance.js` para reproduzir o comportamento sonoro da urna. Não incluí gravações de terceiros nem áudio oficial redistribuído sem autorização.

O TSE identifica o som associado à confirmação como a onomatopeia **Pilili** e informa que ele é o som emitido pela tecla de confirmação. Consulte a fonte oficial antes de substituir os arquivos por material oficial.

Fontes:
